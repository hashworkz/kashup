# Kashish Special Web Application (Vivid+Co Design System)

A cinematic, dark-mode web application built specially for **Kashish** from **Harshit (Dev)**, featuring:

- 🌌 **Vivid+Co Aesthetic System**: Obsidian canvas (`#101010`), Graphite Veil surface (`#495764`), Bone White typography (`#fffdf9`), and an interactive 3D RGB chromatic dispersion caustics glass-cube hero canvas artifact.
- 🔒 **2-Day Ephemeral Private Chat**: Spring Boot backend with scheduled auto-purging (`@Scheduled`) to destroy messages older than 48 hours from Supabase PostgreSQL.
- ✨ **04 September Birthday Special Mode**: Dedicated celebratory birthday view with particle fireworks (`canvas-confetti`), personalized wishes, and secret surprise codes.
- 📸 **Photo Memories Gallery**: Curated memory cards with heart likes counter, category filters, and image upload modal.
- 💌 **Interactive Love Notes**: 3D card-flip grid revealing secret reasons why Kashish is special.

## Tech Stack

- **Backend**: Java 21, Spring Boot 4.1.0, Spring Data JPA, PostgreSQL (Supabase)
- **Frontend**: React 18, Vite, Lucide React, Canvas Confetti, Vanilla CSS Tokens
- **Container**: Multi-stage Dockerfile for one-click deployment on Render, Koyeb, or Railway

## Deployment

Deploy on Render or Koyeb by connecting this repository with Docker builder.
